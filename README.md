
# 🛒 Retail Sales Dashboard – Weather-Based Analysis (Power BI)

## 📌 Overview
This project is an interactive Power BI dashboard that analyzes retail sales performance by integrating weather data such as temperature, rainfall, and seasonality. The objective is to understand how weather conditions influence product demand and support data-driven business decisions.

## 🎯 Objectives
- Analyze sales trends across different weather conditions
- Identify weather-sensitive product categories
- Improve demand forecasting and inventory planning
- Deliver interactive insights using Power BI

## 📊 Features
- Weather vs Sales trend analysis
- Region-wise and category-wise performance tracking
- KPI cards (Total Sales, Growth %, Average Sales)
- Interactive slicers for dynamic filtering
- Data modeling with relationships
- Custom DAX measures for business metrics

## 🛠 Tools & Technologies
- Power BI (Power Query, DAX, Data Modeling)
- Excel / CSV datasets

## 📈 Business Impact
- Enhances demand forecasting accuracy
- Reduces overstock and stockout risks
- Supports strategic retail planning
- Enables data-driven decision making
